# KeyDash — Typing Speed Test

A simple and responsive typing speed test built with **HTML, CSS, and JavaScript**.

## Features

* ⌨️ Real-time typing speed calculation
* 🎯 Accuracy and error tracking
* ⏱️ Multiple test durations — 15s, 30s, 1m, 2m, 5m
* 📊 Easy, Medium, and Hard difficulty levels
* 👤 User name support
* 🌙 Dark and Light mode
* 📱 Responsive design
* 🚫 Paste disabled during the test
* 📝 Dynamic typing text
* 🏆 Result summary with WPM, accuracy, and character count

## Tech Stack

* HTML5
* CSS3
* JavaScript (ES6+)

## Project Structure

```text
KeyDash/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter your name and select the test settings.
5. Click **Start Test** and begin typing.

## How WPM Is Calculated

WPM is calculated using the standard formula:

```text
WPM = (Correct Characters / 5) / Time in Minutes
```
